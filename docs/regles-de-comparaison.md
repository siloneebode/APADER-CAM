Les modèles de référence doivent rester intacts pendant les comparaisons. Une demande de proposition autorise l’ajout d’un modèle indépendant ; elle ne demande pas de redessiner le modèle existant.

Pour le héro de l’accueil, l’utilisateur a explicitement demandé trois propositions : A conserve la présentation actuelle avec photo à droite, B affiche un carrousel d’emplacements wireframe sur tout le fond (photos retirées à la demande explicite de l’utilisateur) et C affiche une photo unique sur tout le fond. L’empreinte du HTML et de la CSS de A est conservée dans reference-hero.json et vérifiée à la construction. Les versions B et C ont des classes et styles séparés.

Modifier un modèle de référence uniquement sur demande explicite de l’utilisateur. Dans ce cas, actualiser sa référence avec la modification autorisée.
